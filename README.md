# Awesome-AI-CLI-Tools

## Top AI CLI Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Terminal AI Agents, Coding Assistants in the CLI, Shell Companions & Developer Terminal Productivity*

**Last updated: October 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **AI CLI Tools**. These tools bring large language models and coding agents directly into the terminal—helping developers write code, run commands, explore repositories, and automate tasks without leaving the command line.



**Examples** include GitHub Copilot CLI, Amazon Q Developer CLI, Warp, Fig, Blackbox AI, Continue, Tabnine CLI, Codeium CLI, Sourcegraph Cody CLI, and Supermaven CLI (the category leaders).



**Open-source emphasis**: The terminal AI space is rich with open tools. **Gemini CLI**, **Aider**, **Open Interpreter**, **ShellGPT**, **AIChat**, and related projects enable powerful, self-hosted or provider-agnostic AI experiences in the CLI. This section is heavily expanded.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[GitHub Copilot CLI](https://github.com/features/copilot)**  

  Official GitHub Copilot experience in the terminal for command suggestions, code explanation, and agent-style assistance.



- **[Amazon Q Developer CLI](https://aws.amazon.com/q/developer/)**  

  AWS’s AI coding assistant available via CLI for code generation, troubleshooting, and cloud-aware development help.



- **[Warp](https://www.warp.dev/)**  

  Modern terminal with a built-in AI agent and agentic features for developers who live in the command line.



- **[Fig (Amazon)](https://fig.io/)**  

  Autocomplete and AI-powered terminal productivity tool (now part of the Amazon ecosystem) focused on developer workflows.



- **[Blackbox AI](https://www.blackbox.ai/)**  

  AI coding and terminal-oriented assistant offering code generation, search, and CLI-related capabilities.



- **[Continue](https://www.continue.dev/)**  

  Open-source-friendly coding assistant with CLI and editor integrations for customizable AI development workflows.



- **[Tabnine CLI](https://www.tabnine.com/)**  

  AI code completion and assistant available through CLI and IDE integrations, with privacy-focused options.



- **[Codeium CLI](https://codeium.com/)**  

  Free-tier-friendly AI coding assistant with terminal and editor support for generation and chat.



- **[Sourcegraph Cody CLI](https://sourcegraph.com/cody)**  

  Code-aware AI assistant from Sourcegraph that can be used via CLI and editor extensions for large codebases.



- **[Supermaven CLI](https://supermaven.com/)**  

  High-speed AI coding assistant with terminal and IDE presence focused on low-latency completions.



## Open-Source GitHub Projects

- **[Gemini CLI](https://github.com/google-gemini/gemini-cli)**  

  Open-source AI agent that brings Gemini execution natively into the terminal — with tools, Google Search grounding, file operations, shell commands, and MCP support.



- **[Aider](https://github.com/Aider-AI/aider)**  

  Popular open-source terminal pair-programming tool that maps your codebase, edits files, and commits changes with cloud or local LLMs.



- **[Open Interpreter](https://github.com/openinterpreter/open-interpreter)**  

  Open-source terminal coding agent that lets LLMs write and execute code, manage files, and control the computer using local or remote models.



- **[ShellGPT](https://github.com/TheR1D/shell_gpt)**  

  Open-source command-line productivity tool powered by LLMs for generating and explaining shell commands.



- **[AIChat](https://github.com/sigoden/aichat)**  

  All-in-one open-source LLM CLI with chat, shell assistance, REPL, and support for many providers and local models.



- **[gptme](https://github.com/gptme/gptme)**  

  Open-source personal AI assistant that runs in the terminal and can use tools, browse, and interact with the system.



- **[Continue (open core)](https://github.com/continuedev/continue)**  

  Open-source coding assistant framework with strong CLI and editor support that can be self-hosted or customized.



- **[OpenCode / community terminal agents](https://github.com/search?q=open+source+coding+agent+cli)**  

  Growing family of open terminal coding agents that work with any model provider and emphasize local-first workflows.



- **[Goose](https://github.com/block/goose)** (and similar extensible agents)  

  Extensible open-source agent frameworks with CLI interfaces that support MCP and multiple LLM backends.



- **[Documentation and terminal AI guides](https://github.com/google-gemini/gemini-cli)**  

  Official docs and community resources for running AI agents natively in the developer terminal.



### Additional Strong Open-Source Options

- Bringing Gemini into the terminal with the official **Gemini CLI**.

- Git-native pair programming via **Aider**.

- Full local computer-use style agents with **Open Interpreter**.

- Lightweight shell command help from **ShellGPT** or **AIChat**.

- Combining open CLI agents with local models (Ollama, llama.cpp, etc.) for private workflows.

- Accepting that commercial tools (GitHub Copilot CLI, Amazon Q, Warp, Cody, Tabnine, Codeium, etc.) still lead in polish, enterprise integration, and seamless IDE + CLI experiences.



**Frameworks for building custom systems**: Install **Gemini CLI**, **Aider**, or **Open Interpreter** → point at your preferred model endpoint → use for coding, shell tasks, and repository exploration. Suitable for developers who want terminal-native AI with maximum control. Many still prefer commercial CLI assistants for convenience and deep platform integration.
